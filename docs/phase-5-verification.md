The MUN protocol is custom `mun-practice-v1`: one human and two AI delegates, openings in ordinal order, caucus cycling or one-to-one negotiation at human boundaries, maximum 60 contributions. It is not an official conference or UN rulebook. Country briefs are user-authored practice positions; optional public HTTPS links are research notes, not independently verified government policy. The model receives pinned briefs and labelled bounded transcript context, has no research tool and cannot change the assigned speaker. Prompt constraints are not proof of model compliance or real-world accuracy.

Hosted acceptance remains outstanding. The Supabase free-project limit prevented project creation. Neon + Clerk is the selected future migration; current code still uses the existing verified Supabase adapter and SQL auth contract. Vercel deployment is deferred at the user's request. Do not paste Neon values into Supabase environment variables or treat the local auth fixture as a production login.

Remaining Phase 5 work includes resolution drafting, amendments, delegate feedback, expanded practice and individually researched advanced formats. None is represented as completed by this starter.
