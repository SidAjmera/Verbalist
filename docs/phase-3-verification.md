## Remaining live checks

No real Supabase project, SMTP/Google configuration, cloud key, local model, native research call or hosting deployment was supplied/configured. The migrations have not been pushed remotely. Docker/hosted CI were not run. The earlier [Phase 1](verification.md) and [Phase 2](phase-2-verification.md) external account/provider/microphone checks still apply.

Before a live release:

1. Apply all three reviewed migrations to the intended dedicated Supabase project; run live advisors and verify RLS/grants/RPC defaults through actual PostgREST with two real accounts/devices. Confirm new exports and account-deletion cascades.
2. Exercise analysis/drills with the actual chosen cloud and local models. Verify JSON compliance, context limits, missing keys, timeout/quota handling, unknown-outcome replay and concurrent saved-turn/version changes. Excerpt validation establishes attribution, not semantic correctness.
3. Review argument extraction, potential-fallacy explanations, rubric fairness, early-finished debates, decisions, coaching/rewrite quality and drill feedback with human evaluators. Confidence is model-reported and uncalibrated; no test here proves grading validity or impartiality. Delivery is unassessed.
4. Opt into native research with a compatible OpenAI model/key. Verify actual completed-search citations, relevance, contradictory sources, unsupported models, failure behavior and billing. Unverified is not false; verified/disputed labels are advisory AI source assessments.
5. Check real mobile/browser graph interaction and chart accessibility, HTTPS/WSS, provider/header redaction, proxy timeouts and private no-store responses. Keyboard-accessible text/excerpt and table alternatives accompany the visualizations.

The [quick-v1 rubric](quick-debate-rubric.md), [API](api.md), [architecture](architecture.md), [security](security.md) and [deployment](deployment.md) document the contracts and limitations. User-owned RPC data is not cryptographically attested and cannot support official rankings. Project-container creation remains deferred.
