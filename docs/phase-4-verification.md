# Phase 4 verification — 7 November 2026 (Singapore)

The implemented story is: three verified accounts create/join a private human room, keep drafts private, exchange text and live audio on shared clocks, obtain an optional advisory ballot, publish an independent human decision, and view consenting practice standings. A separate private event story fills a roster, seeds and schedules matches, then advances reviewed winners. This checkpoint uses local fixture authentication/PostgREST over the actual SQL migrations; it is not a hosted Supabase deployment.

## Scope and remaining live checks

- No hosted Supabase migrations/advisors, real email/Google OAuth, deployment, Docker/hosted CI, paid model call, professional judge verification or public TURN service was configured or verified.
- Internet voice requires operator coturn-compatible TURN configuration and two physical devices on different networks. Test forced relay, blocked UDP/TLS fallback, real microphone permissions, autoplay, suspension, connectivity loss and explicit rejoin. Local native RTP verifies browser media exchange rather than public-network reliability.
- Local audio is the participant's own microphone, off by default and explicitly armed per take, bounded to 25 MB. It remains in page memory for preview/download/discard. It never enters Supabase, ballot requests or exports. Browser dictation is separately consented and may use vendor services. Participants can independently record the call.
- Shared clock/mute enforcement is for compliant clients. Without a central media router, a modified client can bypass local audio controls. Removed members cannot fetch new shared data or signal; compliant peers close their connections on the next presence tick. Previously received text cannot be recalled from another device.
- Only the independent judge confirms results; AI is advisory and transcript-only. Practice points are 3/win, 1/draw, 0/loss, with bilateral room and global opt-in. Simulated AI-assisted decisions receive no credit. Human-reviewed practice standings do not establish official competition integrity or prevent collusion.
- Small events support 2/4/8 players, join-order seeding and single elimination. A cancelled match requires cancelling/recreating the event; no Swiss pairing, bracket repair or tournament chat is claimed.
- Signal expiry is enforced at 60 seconds; physical pruning occurs on later live ticks, not guaranteed while the database is idle. See [deployment](deployment.md) for optional operator cleanup.
- Account deletion removes containing shared rooms/tournaments, their transcripts/results and linked credits for all members. The profile screen discloses this before confirmation. App-link/unload guards protect unsaved local takes, but forced exit/device loss can lose them. Export is membership-filtered and excludes another author's drafts and all invitation/network secrets.
