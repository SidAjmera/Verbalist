# Future schema compatibility (design only)

Phase 5 has started: `20261107131839_phase5_mun_practice.sql` implements `mun_committees`, `mun_delegates`, `mun_messages` and `mun_drafts` for private text-first committee practice. The `mun_resolutions`/amendment work and advanced formats below remain planned. The chosen Neon + Clerk migration is deferred; existing auth contracts are still in use and must be adapted before a Neon deployment.

Phase 3 tables listed below exist in `20261107072739_phase3_intelligence.sql`, together with `analysis_runs`. Phase 4 is implemented in `20261107083107_phase4_multiplayer.sql`: rooms, memberships, hashed invitations, private drafts, shared turns/events, advisory ballots, reviewed results, ranking profiles/credits, tournaments/entries/matches and transient presence/signals. The remaining Phase 5 extensions stay design-only. Use UUID identifiers, server timestamps, indexed foreign keys and explicit ownership/membership policies; add migrations only as a phase is authorized.

| Phase | Tables                                         | Planned relationships and safeguards                                                                                                                                                                         |
| ----- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 3     | arguments                                      | Session + participant + exact turn/text offsets, type, text, confidence, extractor/rubric version, timestamps. Composite session references prevent cross-session pointers.                                  |
| 3     | argument_links                                 | Session, source/target argument, relation and confidence. Unique source/target/relation; reject self-links where meaningless. Access inherits the private session.                                           |
| 3     | judge_ballots                                  | Session, rubric/config version, model provenance, dimension scores, advisory decision, citations to saved turns and uncertainty. Delivery fields require audio evidence.                                     |
| 3     | feedback_reports                               | Session/ballot + account, separate coaching findings, actionable drills and transcript excerpts. Treat AI output as untrusted data.                                                                          |
| 3     | practice_drills, drill_attempts                | Versioned drill definitions and private account attempts. No invented completions; idempotent submissions.                                                                                                   |
| 3     | user_progress, achievements                    | Private aggregates with recomputation provenance and unique account/achievement awards. Derive scores only from completed evaluations.                                                                       |
| 3     | factual_claims, evidence_sources               | Argument/turn references; optional research provider, retrieval time, source URLs, verification status and uncertainty. Unverified does not mean false.                                                      |
| 4     | debate_rooms, room_memberships                 | Owner, private invite-token hash/expiry, session, roles, membership lifecycle and moderator grants. Extend participant identities to authorized human accounts. Never use broad authenticated-role policies. |
| 4     | rankings, tournaments                          | Reviewable ballot references, opt-in profile visibility, participant entries, scheduling, matches/brackets and moderation. Official rankings require human review mechanisms.                                |
| 5     | mun_committees, mun_delegates, mun_resolutions | Specialized sessions, agendas, configured procedure versions, country assignments, researched position sources, caucus turns, resolution/amendment history and authorized committee membership.              |

Format configuration will expand beyond Quick Debate through versioned roles, speaking order, preparation/speaking periods, POI/cross-examination rules, reply speeches and scoring rubrics. Existing sessions retain the format version used at creation. Formal BP, World Schools and Public Forum rules must be researched and validated before enablement; they are not approximated in Phase 1.
