# Phase 5 — MUN practice, first slice

Started at the user's explicit request on 7 November 2026, on branch `phase-5-mun`. Phases 1–4 are published at https://github.com/SidAjmera/Verbalist. The user requested GitHub upload only for now; Vercel deployment and the selected Neon + Clerk migration are deferred. The attempted Supabase project was not created because the free-project limit was reached. Do not publish invented project credentials or claim the existing app has migrated.

Deliver a usable private MUN practice flow: select a committee and agenda, assign the user's country and two AI delegates, pin explicitly user-supplied practice briefs with optional research-note links, write/save an opening, request separately billed AI delegate openings, move into a topic-based caucus or one-to-one negotiation, save/reopen the transcript, pause/resume/finish/cancel, and include these private records in export/deletion. PostgreSQL owns turn order, statuses, versions and replay IDs. Draft versions are independent; all reads/writes require the verified owner. AI keys remain request-scoped and simulations visibly labelled. Retain the blue/black theme and the existing default-off audio behavior.

The procedure is `mun-practice-v1`, a limited educational simulation with three delegates and explicit user control; it is not an official UN or conference rulebook. Practice briefs and pasted links are not verified government policy. The model must follow the supplied brief, acknowledge uncertainty, avoid invented citations and never claim to speak for a real government. No automatic web research, paid model calls or remote schema changes are part of standard testing.

The UN library recommends researching a state's statements, communications, draft sponsorship and voting records, while noting that a state may not have an explicit position on every topic: https://ask.un.org/faq/418224. Keep this research guidance distinct from the simulator's custom procedure.

Later Phase 5 slices: resolution drafting and amendments, grounded delegate feedback, expanded practice and individually researched advanced debate formats. Those features remain outstanding; this first slice starts Phase 5 rather than declaring it finished. Multihuman MUN, official ballots, automated country-policy verification and production deployment are not claimed by the starter flow.
